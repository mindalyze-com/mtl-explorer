## What it is

MTL Explorer puts all your GPS tracks on one map, on your own computer instead
of someone else's cloud.

- Import GPX, FIT, and other GPS files, or sync from Garmin.
- See every activity on one map. Filter and color them.
- Follow your statistics and trends over the years.
- Replay an activity in 3D.
- Plan new routes.

It runs with Docker Compose on a PC, NAS, home lab, or server. See the
[feature overview](documentation/features.md) for everything it can do.

[Why I built MTL Explorer](documentation/project/background.md): the project started
from the need to see thousands of Garmin tracks on one map, then grew into a
personal exploration, planning, and statistics tool.

MTL Explorer is a long-running personal project. This repository is a public
mirror, so its history is shorter than the project's. AI tools helped polish
parts of the app, but the app was not generated by AI.

## Quick start

You need Docker with Compose. On Windows and macOS, install Docker Desktop.
Check with `docker compose version`.

1. Start MTL Explorer:

   * **macOS, Linux, WSL, or Git Bash**:
     ```bash
     mkdir mtl-explorer && cd mtl-explorer
     curl -fsSL -o docker-compose.yml https://raw.githubusercontent.com/mindalyze-com/mtl-explorer/main/docker-compose.yml
     docker compose up -d
     ```
   * **Windows PowerShell**:
     ```powershell
     mkdir mtl-explorer; cd mtl-explorer
     Invoke-WebRequest -Uri "https://raw.githubusercontent.com/mindalyze-com/mtl-explorer/main/docker-compose.yml" -OutFile "docker-compose.yml"
     docker compose up -d
     ```

   The first start downloads the images and sets up the database. This can
   take several minutes.

2. Open **`http://localhost:18080/mtl/`** and sign in:
   * **User**: `mtl`
   * **Password**: `change-me`

3. Add your tracks: upload them under **Settings → Import & sync**, or copy
   them into `./data/gpx/`. See the
   [supported formats](https://mtl-explorer.com/supported-gps-formats/).

**Change the default password before other people or the internet can reach
MTL Explorer.** See [Login and credentials](documentation/administration/configuration/authentication.md).
For storage, offline maps, and HTTPS, see the [administration guide](documentation/administration/README.md).

## Repository layout

- `mtl-server/` - Spring Boot backend.
- `mtl-client/` - Vue 3 and TypeScript PWA.
- `mtl-api/` - OpenAPI schema and generated TypeScript clients.
- `docker-brouter/` - BRouter routing service.
- `docker-maps/` - optional local vector map service.
- `docker-location-search/` - GeoNames SQLite location-search service.
- `docker/` - import and demo-data helpers.
