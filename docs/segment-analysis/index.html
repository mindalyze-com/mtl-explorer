Segment analysis

Compare repeated routes between map checkpoints.

Define a segment by placing checkpoints on the map. MTL Explorer searches the archive for tracks that crossed them, then compares the matching attempts.

Try segments in the demo View the track map

How a segment comparison works.

A segment is based on geographic gates rather than a track name. This allows the same section to be found across activities recorded on different days.

Place checkpoints

Draw the start, end, and any intermediate gates directly on the map.

Search the archive

MTL Explorer finds imported tracks that crossed the gates in the required order.

Compare the results

Review elapsed time, distance, pacing, and the available activity measurements.

Replay attempts

Display matching tracks together and replay their progress on the map.

Results

Inspect every matching attempt.

The results table provides a consistent view across all tracks that match the checkpoints. Open an attempt to inspect its graphs and map position.

  • Compare repeated climbs, descents, trail sections, or commutes.
  • Keep the source activities in the private archive.
  • Use the same segment again as new tracks are imported.

Comparison

Review timing and effort together.

Side-by-side charts make it easier to see where attempts differed. The available series depend on what the original activity files recorded.

Replay mode provides a map-based comparison when chart values alone do not explain the difference.
