Docker installation

Run MTL Explorer on your own host.

One Docker Compose file starts everything MTL Explorer needs: the app, its database, route planning, and place search. Your data stays in folders on your own computer.

Open the full install guide View the repository

Quick start

You need Docker with Compose. On Windows and macOS, install Docker Desktop. Then run:

mkdir mtl-explorer
cd mtl-explorer
curl -fsSL -o docker-compose.yml \
  https://raw.githubusercontent.com/mindalyze-com/mtl-explorer/main/docker-compose.yml
docker compose up -d

Open http://localhost:18080/mtl/ and sign in with user mtl and password change-me. Change the password before other people or the internet can reach it.

Get started

Your data stays in local folders.

MTL Explorer keeps everything in the data/ folder next to docker-compose.yml: your tracks, photos, and database. Back up this folder.

Track files

Your original GPS files stay in the folder where you put them. MTL Explorer never changes them.

Database

The database holds your processed tracks, settings, filters, segments, and planned routes.

Optional offline maps

You can also host the base map yourself. The whole-world map needs about 200 GB of disk space.

Updates

MTL Explorer tells you when a new release is out. Open Settings → Updates to read the release notes, then back up and run:

docker compose pull
docker compose up -d

Some releases need extra steps; the release notes say so. To pin exact image versions, use the digests in the release manifest.

The update check is optional and the app works without internet access. To turn it off, set MTL_UPDATES_ENABLED=false in .env. See Updates for details.
