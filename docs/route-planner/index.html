Route planner

Plan a route and export the result as GPX.

Place waypoints on the map and let the configured BRouter service calculate each leg. Distance, ascent, and the elevation profile update as the plan changes.

Try the route planner Install with Docker

Build the route one leg at a time.

The planner keeps the original waypoints and the calculated path. Moving one waypoint only recalculates the affected legs.

Routing profiles

Select a configured BRouter profile for the type of route you want to plan.

Live distance and ascent

Route totals and the elevation profile update after each successful routing change.

Editable plans

Save a plan to the local database and open it later with its original waypoints.

GPX export

Export the calculated geometry as a GPX file for another application or GPS device.

Map context

Plan beside existing tracks and public trail data.

The route planner uses the same map as the GPS archive. Existing activities can provide context, while optional overlays show waymarked hiking and cycling routes.

  • Switch between the configured base maps.
  • Show or hide archived tracks while planning.
  • Use public trail overlays as a visual reference.

Local plans

Keep planned routes with the archive.

Plans are stored on the MTL Explorer server. They remain separate from imported activities and can be edited without modifying the original track archive.

BRouter is included as a sidecar in the standard Docker Compose setup.
