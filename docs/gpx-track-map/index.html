GPS track map

Map your complete GPS track archive.

MTL Explorer imports activity files into a self-hosted archive. It can display thousands of tracks together, then narrow the map by activity, year, or a custom filter.

Open the demo Install with Docker

Keep different file types in one archive.

MTL Explorer accepts common GPS and activity formats, including GPX, FIT, TCX, KML/KMZ, IGC, NMEA, GeoJSON, and GDB. Garmin imports can run alongside files placed in the import folder.

Review supported formats Garmin Connect import

Local storage

The files, processed tracks, photographs, database, and optional map tiles stay on the host you control.

Background processing

Imports are indexed in the background. Duplicate detection and outlier handling prepare the tracks for map and statistics views.

Track details

Select a track to inspect its date, distance, time, moving speed, elevation, energy, and other available measurements.

Photographs

Photographs with location data can appear beside the matching tracks, without publishing the archive to an external service.

Filters

Change what the map and statistics include.

Saved filters control the visible subset of the archive. Tracks can be grouped by activity or year, while SQL-based rules support more specific selections.

The same active selection also controls the private GPS heatmap.

  • Color tracks by activity type or year.
  • Use the same selected subset in map and statistics views.
  • Save focused filters for repeated use.

Statistics

Review totals and changes over time.

Statistics use the active archive selection. Views can compare distance, moving time, energy, and activity counts across years, quarters, months, or weeks.

The exploration score reports how much new territory an activity added to the existing archive.

Use the archive from a mobile browser.

The responsive interface includes the track map, statistics, segment tools, and current GPS position. Cached tracks and map data provide basic support when the network is unavailable.
