Garmin Connect import

Bring Garmin activities into your private archive.

MTL Explorer can download your new Garmin Connect activities automatically. The files are saved on your own computer and appear on the map like any other track.

Install MTL Explorer View the track archive

Set it up once

Turn on Garmin sync in the server settings and enter your Garmin Connect login.

Sync

Open Settings → Import & sync → Garmin and choose Sync now, or let it run on its schedule.

Only new activities

Activities you already have are not downloaded again.

Explore

New activities are imported and show up on the map and in your statistics.

Garmin import guide

Failed downloads get a second try.

If downloading an activity times out, MTL Explorer tries again with the activity's original FIT file.

No duplicates

MTL Explorer remembers each Garmin activity, so later syncs skip it.

Second try

The retry usually helps with timeouts. It can't fix every error, and the second download can fail too.

See what happened

Check Garmin command output in Settings → Import & sync. Tool status is in Settings → Maintenance → Advanced tools.

Like any other track

Downloaded activities work everywhere: filters, map, statistics, and segments.

Sync is skipped

A sync is skipped when Garmin sync is off, another sync is running, or files are still being imported. Check the reason shown and wait for the current work to finish.

Sign-in fails

Read the error and check your Garmin login in the server settings. Retrying won't fix a sign-in problem. Meanwhile, export activities by hand from Garmin Connect, and don't keep restarting a failing sync.

Community integration MTL Explorer uses community tools to download from Garmin. It is not an official Garmin integration, and it can stop working if Garmin changes its service.
