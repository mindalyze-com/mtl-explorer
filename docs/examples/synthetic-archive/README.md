MTL Explorer synthetic archive

Twelve fictional loop tracks near latitude/longitude 0,0: eight in June 2024
and four in June 2025. Each has 181 points, timestamps 12 seconds apart, and
synthetic elevation. These are mathematical examples, not navigation routes.
No recorded or private tracks, street maps, or external datasets were used.

Unzip `synthetic-tracks.zip`, then import the GPX files into a test installation.
Use the archive map and change the year filter to compare the selections.

Regenerate from the repository root:

```sh
python3 documentation/tools/website/generate_examples.py
```
