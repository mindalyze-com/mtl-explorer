# Contributing

Read the [contribution policy](../../.github/CONTRIBUTING.md), [code of conduct](../../.github/CODE_OF_CONDUCT.md), and [security policy](../../.github/SECURITY.md). The contributor agreement and license terms remain in their legal sources.

Start with [development setup](../development/getting-started.md) and keep changes focused. Follow [repository instructions](../../AGENTS.md). GitHub is a public mirror: apply suitable patch ideas manually; never merge its branches into the private workspace.

Update the relevant user guide and current architecture with behavior changes. Keep private deployment details, source tracks, health records, and development history out of public documentation.
