# MTL Explorer Release v.0.6.1

## Features
- Minor release only.

## Fixes And Changes

- Added activity, statistics, and highlight curation controls to Track Details quality.
- Improved Garmin and GPX activity detection, including rowing and common Garmin activity aliases.
- Preserved the 2D map camera when leaving 3D replay.
- Fixed animation speed controls so slow is left and fast is right.
- Improved Track Details mobile graph controls with a compact tuning toggle.
- Made Track Details and mini-map opening more stable and less jumpy.
- Added focused frontend and backend test coverage for these changes.
