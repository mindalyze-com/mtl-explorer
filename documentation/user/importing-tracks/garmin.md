# Import from Garmin

Garmin sync is optional and off by default. Your administrator must first
[set it up](../../administration/garmin.md).

1. Open **Settings → Import & sync → Garmin** and select **Sync now**.
2. Check the command output for errors.
3. Watch **Settings → Processing** while the activities are imported.
4. Open **Review** if files need attention.

Activities that were already downloaded are skipped next time. If a download
fails, MTL Explorer tries once more in a different format. Some errors don't
name the activity; check the command output and the
[administrator troubleshooting guide](../../administration/troubleshooting.md).
