# Compare segment attempts

Select attempts in [Segments](segments.md), then choose **Compare**. Pick a
reference attempt; it is marked **R**.

The first chart shows how far ahead or behind each attempt was at the same distance.
The same distance doesn't always mean the same place on the ground, for example
if one attempt took a detour. Point at a chart, tap it, or use the keyboard to see values for all
attempts at that spot. Heart rate and effort columns appear when that data exists.

Ghosts show where the other attempts were when the reference reached that point.
**Open Replay here** starts a [replay](../replay.md) at that point.

**Graph settings** changes the detail level and chart height.
