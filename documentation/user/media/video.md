# Play video

Open a video in the viewer. It plays directly if your browser supports its
format.

If it doesn't, choose compatible playback when offered:

1. Choose a quality.
2. Wait while the server converts the video.
3. Play it.

You can cancel the conversion, or come back later to a finished one. The
original file is never changed and can always be downloaded.

Converting video takes server resources. If it fails, try again, then check
**Settings → Processing** and the [server logs](../../administration/maintenance/logs.md).
