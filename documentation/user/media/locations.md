# Set a photo location

The viewer shows where a photo's position comes from:

- **Photo GPS**: saved in the photo by the camera.
- **Estimated**: placed along a track recorded at the same time.
- **Set by you**: placed by hand.
- **Position unknown**: no location available.

## Set a location

1. Open **Track details → Media → Photo tools → Adjust locations**.
2. Select **Set location**.
3. Enter the coordinates and an optional note.
4. Click **Save location**.

Your location takes priority. To undo it, choose **Edit location → Clear
assignment**; the photo goes back to its GPS or estimated position. The photo
file itself is never changed.

If an estimated position is wrong, the camera clock may be off; see
[correct camera time](capture-time.md).
