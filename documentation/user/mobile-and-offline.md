# Mobile and offline use

MTL Explorer works in your phone's browser. The bottom toolbar has **GPS**,
**Map**, **Filter**, and **Planner**; the other tools are under **More**. You
can add it to your home screen with your browser's install option.

## Show your position

Tap **GPS** and allow location access in your browser. This only works over
HTTPS. MTL Explorer shows where you are but does not record your activity.

## Use it offline

Offline, you only see what this browser has already loaded. Before a trip, open
the map area and tracks you need while you are still online. Route planning,
search, and photos that weren't loaded before won't work offline.

Offline maps on the server are different: they still need a connection to your
server. Some map layers, like 3D terrain and trail overlays, always need the
internet.

**Clear & sign out** in **Settings → Session** removes the saved data. This guide
is also available offline once the app has been opened.
