# Settings

Open **Settings** on a computer, or **More → Settings** on a phone.

| Section | What you find there |
| --- | --- |
| Overview | Status and actions that need your attention |
| Preferences | Theme, language format, and units |
| Updates | New releases and how to install them |
| Session | Sign out and clear local data |
| Import & sync | Upload files, Garmin, and Google Health |
| Processing | Import progress and errors |
| Data status | Whether your browser shows the latest data |
| Maintenance | Rescan files and advanced tools |
| Logs | Server and browser errors |
| System information | Versions of all components |

## Preferences

Choose **Metric** or **Imperial (US)** units. The locale sets how dates and
numbers look. Some preferences are saved only in this browser. **Use default**
removes your unit choice.

## Processing

**Processing** shows what MTL Explorer is working on: imports, syncs, and
calculations. Click **Details** on a row to see progress and any errors. The
info icon explains each task.

## Session

**Sign out** only logs you out. **Clear & sign out** also removes the maps and
tracks saved in this browser, so offline use stops working until you load them
again.

**Session** also shows your login reference. If you report a problem, click
**Copy** and include it. It is not a password and cannot be used to sign in.
