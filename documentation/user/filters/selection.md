# Select tracks

The filter decides which tracks you see. The map, track list, statistics, and
segment analysis all use it.

1. Open **Filter**.
2. Choose a view from the view picker.
3. Set criteria such as dates or activity type.
4. Choose which categories to include, and check the number of matching tracks.

Use pause and resume to turn the filter off for a moment. **Reset** clears it,
with an undo option.

For walking and hiking, include the **On foot** category. Choose the Walking type
for walks only.

Changing the filter never deletes anything. Health has its own dates. Photos
follow the time span of your filtered tracks. Tracks excluded from statistics in [Review](../tracks/source-review.md) stay excluded.
