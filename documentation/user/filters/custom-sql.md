# Custom SQL views

If the standard views can't select the tracks you want, write your own view in
SQL. Open the custom SQL editor from **Filter** and check the SQL preview before
you apply it.

- Start from an existing view.
- Keep track selection and color grouping separate.
- Use the unit shown next to each input.

If the SQL is invalid, you'll see an error. Fix it before trusting the counts.

For field names, grouping columns, parameters, and examples, see
[the filter reference](../../architecture/filters.md).
