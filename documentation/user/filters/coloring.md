# Color the map

Open **Filter** and choose how to color the tracks: by activity type, year,
weekday, or another grouping the view offers. The legend explains the colors.

Colors only change how tracks look. They don't change which tracks count in
your statistics.

To compare years, first choose the dates to include, then color by year. For a
single year, set the filter to that year instead.

For your own groupings, use [a custom SQL view](custom-sql.md).
