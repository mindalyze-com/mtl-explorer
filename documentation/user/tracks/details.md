# Track details

Click a track on the map or in the [track list](browsing.md) to open its details.
On a phone, tap **Restore panel size** before dragging the panel down to make it
smaller. If you opened details from Statistics or Filter, **Back** returns to that list.

| Tab | What it shows |
| --- | --- |
| **Overview** | Distance, time, [energy](../analysis/energy.md), and heart rate |
| **Graphs** | Speed, elevation, and other values over time or distance |
| **Quality** | Why a value is missing or unreliable |
| **Related** | Other tracks nearby or on the same route |
| **Media** | Photos and videos from this activity |
| **Events** | Breaks and GPS gaps |

Values can be missing when the file has gaps or no timestamps. Missing is not
the same as zero.

## Events

**Events** lists breaks and GPS gaps with their start, end, and duration. Click
one to show it on the map. A GPS gap means positions are missing; it doesn't
prove you stopped. Use the map's **Events** switch to show or hide all event
markers.

## Download and replay

Download the original file or a GPX version. **3D Replay** needs a track with
timestamps and no big gaps; see [replay](../replay.md).
