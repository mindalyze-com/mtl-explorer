# Statistics overview

Open **Statistics → Overview** to see your totals, activity types, highlights,
recent activity, and milestones. It uses the tracks in your current
[filter](../filters/selection.md).

Click a highlight or period to see the tracks behind it. **Back** returns to
where you were.

Some values may be missing for some tracks, for example when a file has no
timestamps or elevation. Missing is not the same as zero, so totals for
distance, time, and energy can cover different tracks.

To compare periods, set your filter first, then open [Trends](trends.md).
