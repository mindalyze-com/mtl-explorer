# User guide

Keep your GPS tracks, photos, and optional health data on your own installation.

1. **[Get started](getting-started.md)**\
   Import a few tracks and learn the main tools.
2. **[Import tracks](importing-tracks/README.md)**\
   Add GPS files or sync from Garmin.
3. **[Explore the map](map.md)**\
   Choose tracks with [filters](filters/README.md) and open [track details](tracks/README.md).
4. **[Review statistics](statistics/README.md)**\
   Follow your trends and compare efforts with [analysis](analysis/README.md).
5. **[Plan routes and places](planning.md)**\
   Plan a route or [replay an activity](replay.md).
6. **[Browse photos and videos](media/README.md)**\
   See your media on the map, and optional [health data](health/README.md).

Also see [Settings](settings.md), [mobile and offline use](mobile-and-offline.md),
and [troubleshooting](troubleshooting.md). To install or configure the server,
see [Administration](../administration/README.md).
