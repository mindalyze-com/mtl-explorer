# Full regression

Use this workflow for a complete end-user run with frozen coverage and resumable packets.

1. [Read the workflow](workflow.md).
2. [Review the coverage plan](coverage-plan.md).
3. [Start a run](start.md) with the [goal prompt](goal-prompt.md).
4. [Record packets](packet-template.md) and check the finalization gate.

Dated run evidence is stored internally. New coverage applies to new runs; existing runs retain their own snapshots.
