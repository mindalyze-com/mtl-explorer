# Documentation screenshots

Use real app captures with public or fully synthetic data. Prefer compact WebP;
use PNG only when needed. Keep raw images and recordings on the mounted external drive.

Record the app/build, dataset source, workflow, and capture date with the topic or evidence. Keep visible controls and labels readable. Include compact captures for working functions in full regression reports.

Reuse existing validated assets where they describe the current flow. [Feature capture notes](../../../docs/assets/feature-showcase/README.md) and [Health capture notes](../../../docs/assets/feature-showcase/google-health-sources.md) record their origins.

The [Health image helper](../../tools/website/prepare_health_screenshots.py) encodes established screenshot sizes without changing the content. Update dimensions, source notes, and image references together.
