# Administration

Install and run your own MTL Explorer. To learn how to use the app, see the
[User guide](../user/README.md).

1. [Install](installation/README.md) and import a few test files.
2. [Configure](configuration/README.md) the login, data folders, and HTTPS.
3. Optional: connect [Garmin](garmin.md) or [Google Health](google-health.md).
4. Check the [map, routing, and search services](services/README.md).
5. Set up [backups and updates](maintenance/README.md).

If something fails, see [troubleshooting](troubleshooting.md). Keep passwords,
tracks, photos, health data, and backups private.
