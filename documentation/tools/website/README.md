# Website tooling

See [generation, checks, and preview](../../development/website/generation.md)
and [documentation authoring](../../development/website/documentation.md).

`generate_documentation.py` writes `docs/docs/` and `mtl-client/public/guide/`.
`generate_releases.py` writes release pages and marked news regions.
Use `--check` to verify freshness without writing. These helpers do not publish.
