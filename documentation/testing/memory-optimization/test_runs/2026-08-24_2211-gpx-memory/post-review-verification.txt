checks therefore ran in maven:3.9.16-eclipse-temurin-25 on linux/amd64. The
commands below use MTL_PROJECT_ROOT for the repository root and
MTL_MAVEN_CACHE_ROOT for the local Maven cache directory.

3. Focused GPX store, indexer, media, and controller regression

The linux/amd64 container's default spawn helper failed intermittently while
starting temporary test scripts. The same video class had already passed in the
isolated run above. The exact broader suite was rerun with the JDK's FORK launch
mechanism to avoid that emulation-specific helper.

Command:
  docker run --rm --platform linux/amd64 --user 501:20 \
    -e MAVEN_CONFIG=/tmp/maven-config \
    -e MAVEN_OPTS=-Duser.home=/tmp/maven-config \
    -e JAVA_TOOL_OPTIONS=-Djdk.lang.Process.launchMechanism=FORK \
    -v "${MTL_MAVEN_CACHE_ROOT}:/tmp/maven-config" \
    -v "${MTL_PROJECT_ROOT}:/workspace" \
    -w /workspace maven:3.9.16-eclipse-temurin-25 \
    mvn -pl mtl-server \
    -Dtest=GPXStoreServiceDenoiseTest,GPXStoreServiceMovingWindowTest,ProcessingFileIndexerObserverTest,IndexerStatusServiceTest,FileIndexerImplTest,MediaIndexerTest,MediaProcessingWorkerTest,MediaControllerContentTest,MediaControllerPositionTest,MediaControllerTrendTest,MediaProcessLimiterTest,VideoThumbnailServiceTest,VideoTranscodeSessionServiceTest,VideoTranscodeControllerTest \
    test

Result:
  Tests run: 94, Failures: 0, Errors: 0, Skipped: 1
  BUILD SUCCESS

This 94-test set contains the 26-test generated-image and video set from step 1.
The unique current-tree total across steps 2 and 3 is therefore 692 tests run,
691 passed, and one skipped.
