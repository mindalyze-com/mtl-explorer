Motorized Tracks Filter only for tracks which are motorized (not human powered). DATE & TIME Tracks by year Filters the tracks by year. If multiple years are given then the year will be optionally used for coloring. Tracks by day Groups matching tracks by calendar day using the track start date. This is useful for multi-day tours, holidays, bikepacking trips, hikes, or road trips where each daily activity should receive its own map color, making it easier to see which sections were done on which day. The standard base filter is applied first, so normal date, geo area, successful-load, and unique-track constraints still apply. Tracks spanning midnight are assigned to their start day. Tracks by quarter Groups matching tracks into calendar quarters from the track start date: Q1, Q2, Q3, and Q4. This is useful for spotting broad seasonal or yearly patterns without assuming northern-hemisphere season names. The standard base filter is applied first, so normal date, geo area, successful-load, and unique-track constraints still apply. Tracks by day of week Groups matching tracks by the weekday of the track start date, ordered Monday through Sunday. This is useful for spotting weekday commute habits, weekend trips, regular training days, or differences between workday and leisure routes. The group is based on the track start date, not on every point inside a long track. Tracks by time of day Groups matching tracks by the time of day they started: Night, Morning, Midday, Afternoon, Evening, and Late Night.
