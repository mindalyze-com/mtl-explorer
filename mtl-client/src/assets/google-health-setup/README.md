# Google Health setup screenshots

The setup assistant loads these optional, redacted WebP files as compact references. Users can select a reference to
open the full image:

- `01-enable-api.webp`
- `02-auth-platform.webp` (Audience page after initial app setup; shown in Branding)
- `03-audience-test-user.webp`
- `04-web-client.webp` (advanced proxy mode only)
- `05-data-access-scopes.webp` (Data access page listing all four Google Health scopes before saving)
- `06-google-consent.webp`

Remove account emails, project identifiers, client IDs, and client secrets before adding an image.
